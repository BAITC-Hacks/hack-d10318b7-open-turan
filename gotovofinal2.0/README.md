# Meeting Notes 4.0

Локальное приложение для записи встреч, расшифровки русской и казахской речи,
проверки решений и задач и экспорта отредактированного протокола в Word.

## Быстрый запуск на этом компьютере

1. Откройте папку проекта и дважды щёлкните **start.bat**.
2. Браузер откроется автоматически: **http://127.0.0.1:8000**.
3. Оставьте окно сервера открытым. Для остановки нажмите Ctrl+C.
4. При повторном запуске установленные пакеты не скачиваются заново.

Python 3.11+ необходим. При первом запуске start.bat создаст отдельное окружение venv.
При переносе на другой компьютер создайте окружение заново через start.bat.

## Три способа работы

- **Загрузить файл**: выберите или перетащите запись, проверьте параметры,
  нажмите «Создать протокол». До 25 МБ; MP3, WAV, M4A, MP4, WebM, OGG, FLAC, MPEG/MPGA.
- **Записать встречу**: в Chrome/Edge выберите вкладку Meet со звуком или экран
  с системным звуком для Zoom. При необходимости добавьте свой микрофон.
  После остановки начнётся обработка; исходную запись можно отдельно сохранить.
- **Готовый текст**: вставьте расшифровку либо попробуйте отмеченный учебный пример.

После обработки отредактируйте резюме, решения, участников, ответственных и сроки.
Кнопка «Скачать Word» формирует документ по текущим значениям полей.
Заголовки документа соответствуют выбранному языку: русский или қазақша.

Если Ollama недоступна или её ответ не прошёл проверку цитат, расшифровка
сохраняется в редакторе. Заполните резюме и задачи вручную, затем скачайте Word.
Приложение не подставляет вымышленные результаты вместо ответа модели.

## Настройка локальных моделей

**setup_models.bat** устанавливает самостоятельный CPU-вариант Ollama в
tools/ollama, скачивает qwen2.5:3b и Whisper small. Нужны интернет и несколько
гигабайт свободного места. Файлы берутся из официального релиза Ollama и
репозитория Systran/faster-whisper-small на Hugging Face.

Ollama запускается автоматически вместе с приложением. Веса находятся в models/,
журнал — logs/ollama.log. Служебные файлы Ollama могут создаваться в
пользовательской папке .ollama. Приложение не добавляется в автозагрузку Windows.
В комплект включены CPU-библиотеки; для GPU установите официальный Ollama
отдельно. Уже работающий локальный сервер Ollama используется без перезапуска.

Настройки в .env:
- WHISPER_MODEL=small — модель распознавания.
- WHISPER_DEVICE=cpu — устройство распознавания.
- OLLAMA_MODEL=qwen2.5:3b — модель анализа.
- OLLAMA_URL=http://127.0.0.1:11434 — только локальный адрес.

После изменения модели запустите setup_models.bat, затем перезапустите start.bat.
При недостатке памяти можно выбрать qwen2.5:1.5b, но качество будет ниже.
Статус компонентов виден в интерфейсе и на http://127.0.0.1:8000/health.
При первой загрузке модели окно приложения может долго показывать обработку.

## Хранение и границы

- Звук и текст обрабатываются на компьютере. Облачные API не используются.
- Исходный файл загрузки удаляется после обработки. Браузерная запись доступна
  по ссылке «Сохранить исходную запись» до перезагрузки страницы или новой записи.
- Последние 20 результатов находятся **в памяти сервера**, без постоянной базы.
  После перезапуска сервера они исчезают. Скачивайте готовые документы.
- Перезагрузка вкладки возобновляет ожидание активной обработки. Нескачанные
  ручные правки готового протокола при перезагрузке не сохраняются.
- Одновременно принимаются до двух заданий. Распознавание аудио выполняется
  последовательно, чтобы не перегружать память.
- Текст — до 60 000 символов. Для больших встреч используйте несколько файлов.
- Модель может ошибаться: проверяйте задачи и подтверждающие цитаты.
  Акустической диаризации нет; имена берутся только из самой речи.
- Браузеру нужен звук выбранного источника; если в файле нет голоса,
  восстановить его нельзя. Сообщите участникам о записи заранее.
- Сервер работает на 127.0.0.1. Аккаунты и коллективный доступ не предусмотрены.

## Проверка

Из папки проекта:

    venv\Scripts\python.exe -m unittest discover -s tests -v

Тесты проверяют обработку текста, сохранение расшифровки при ошибке модели,
экспорт DOCX на русском и казахском, очистку временных файлов, лимиты заданий
и файлов, проверку дат/полей, состояние моделей и локальные статические файлы.
Для этих тестов загрузка моделей не требуется.

## Файлы

- main.py — FastAPI, очередь, загрузки и экспорт.
- utils.py — Whisper, Ollama, проверка схемы ответа и цитат.
- docx_generator.py — документ Word.
- static/index.html, style.css, app.js — интерфейс без внешних CDN.
- launcher.py, start.bat — запуск сервера и браузера.
- setup_models.py, setup_models.bat — настройка моделей.
- tests/test_local_protocol.py — проверки.
- GET /docs — интерактивная документация API.
- POST /transcript — готовый текст; POST /transcribe — аудио.
- GET /transcribe/{task_id} — состояние обработки.
- POST /transcribe/{task_id}/document — экспорт после проверки.

Официальная информация о локальном Ollama:
