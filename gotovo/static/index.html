Готово
Для записи нажмите «Начать запись», затем выберите источник со звуком.
Google MeetВыберите вкладку встречи и включите «Передавать звук вкладки». Убедитесь, что голоса участников слышны в этой вкладке.
ZoomВыберите окно/экран и включите системный звук. Для Zoom в браузере можно выбрать вкладку и передавать её звук.
СогласиеСообщите всем участникам о записи и соблюдайте правила организации.

Важное ограничение: пока нет автоматического распознавания людей по голосу. Имена добавляются только если участник явно назвал себя.
