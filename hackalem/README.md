# Кеңестерді автохаттамалау және тапсырмаларды бекіту

HackAlem AI хакатонының «Самұрық-Қазына» кейсіне арналған демонстрациялық MVP.
Жүйе аудионы мәтінге айналдырады, қысқаша қорытынды мен тапсырмалар жобасын
дайындайды және пайдаланушы тексерген нәтижені DOCX құжатына шығарады.

## Қазіргі мәртебе

Бұл нұсқа OpenAI API қолданады: аудио Whisper-ге, транскрипт GPT-4o-ға жіберіледі.
Ол негізгі пайдаланушы сценарийін жергілікті модельдерге қажет есептеу
инфрақұрылымын дайындамай көрсету үшін пайдаланылған.

**Кейс сыртқы бұлттық API-ге аудио мен мәтін жіберуге тыйым салады.
Сондықтан бұл демонстрация кейстің жабық контур талабын орындамайды.**
Жергілікті модельдерге көшу — төменде сипатталған жоспар; дайын функция емес.
Құпия жұмыс жазбаларын бұл нұсқаға жүктеуге болмайды. Демонстрацияда синтетикалық
немесе тиісті рұқсаты бар, құпия деректерден тазартылған жазбалар қолданылады.

## Іске асырылған мүмкіндіктер

- MP3, WAV, M4A және MP4 жүктеу; бос файлды және 25 МБ-тан үлкен файлды қабылдамау.
- Қазақ, орыс және аралас сөйлеуге арналған тіл таңдауы немесе автоматты анықтау.
- Whisper жауабындағы сөйлеудің болмау ықтималдығы мен тану көрсеткіштері бойынша
  сенімділігі төмен бөліктерді өткізіп жіберу және пайдаланушыға ескерту.
- GPT-4o жауабына қатаң JSON схемасы және Pydantic арқылы қосымша тексеру.
- Әр тапсырманың бастапқы дәлел үзіндісін транскрипттен тексеру.
- Түсініксіз мәтінді, тапсырмасы жоқ кеңесті және техникалық қатені ажырату.
- Жаңа файл, тіл немесе күн өзгергенде алдыңғы нәтижені тазарту.
- Өңдеудің барлық кезеңі аяқталғаннан кейін ғана нәтижені сақтау.
- Бос тапсырмалар кестесіне де қолмен жол қосу; жолдарды өзгерту және өшіру.
- Деректер өзгергенде бұрын дайындалған DOCX-ті жарамсыз ету.
- A4 пішіміндегі DOCX, бос мәндерге «Анықталмады», кесте тақырыбын келесі бетте қайталау.

Аттар тек мәтіндегі анық белгілерден алынады. Дауыс бойынша диаризация,
сөйлеушіні биометриялық тану және репликалардың уақыт бойынша сәйкестігі іске асырылмаған.

## Құрылымы

| Файл | Міндеті |
|---|---|
| `app.py` | Streamlit интерфейсі, сессия күйі, түзету және экспорт |
| `utils.py` | API сұраныстары, жауап схемасы, мәтін мен тапсырмаларды тексеру |
| `docx_generator.py` | DOCX құжатын құрастыру |
| `requirements.txt` | Тікелей тәуелділіктердің бекітілген нұсқалары |
| `README.md` | Орнату, тексеру, шектеулер және көшу жоспары |

Өңдеу жолы: аудио → Whisper API → транскрипт → GPT-4o → схема мен дәлелді тексеру
→ пайдаланушының түзетуі → DOCX.

Технологиялар: Python 3.11, Streamlit, OpenAI Python SDK, Pydantic, Pandas,
python-docx. Pandas бос және толтырылған кестені бірдей құрылыммен береді.

## Орнату және іске қосу

Бес файлды бір `hackalem` қалтасына сақтаңыз. Командаларды сол қалтада орындаңыз.
OpenAI API-ге қолжетімділік, жарамды кілт және жеткілікті есептік лимит қажет.
API қолдану есептік жазбаның тарифі бойынша төленеді.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Linux немесе macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

Браузерде `http://localhost:8501` мекенжайын ашыңыз. Бүйірлік панельде API кілтін,
аудио тілін және кеңес күнін енгізіңіз. Файлды жүктеп, «Өңдеу» батырмасын басыңыз.
Транскриптті, қорытындыны және тапсырмаларды тексеріңіз. Кестені түзетіп,
«Тапсырмаларды бекіту және DOCX дайындау», кейін «Хаттаманы жүктеу» батырмасын басыңыз.

Атауды, кестені немесе транскриптті қосу белгісін өзгертсеңіз, DOCX-ті қайта дайындау керек.
Тілді немесе кеңес күнін өзгертсеңіз, аудионы қайта өңдеу керек.
API кілті кодқа жазылмайды және қосымша оны тұрақты файлға сақтамайды.
Кілтті, `.venv` қалтасын және құпия жазбаларды GitHub-қа жүктемеңіз.

## Қайталанатын тексеру

1. Қазақша, орысша және аралас тілде жеке сынақ жазбаларын дайындаңыз.
   Әрқайсысына адам тексерген транскрипт пен күтілетін тапсырмалар тізімін жасаңыз.
2. Тапсырманың мазмұнын, жауапты тұлғасын және мерзімін жеке салыстырыңыз.
   №1 берілген хаттаманың қорытындысында 10 тапсырма, №2-де 6 біріктірілген жол бар.
   Бір күрделі тапсырманы бірнеше жолға бөлуге болады; мазмұны жоғалмауы керек.
3. А кеңесін өңдеңіз. Б файлын жүктегенде А нәтижелері бірден жойылғанын тексеріңіз.
   Б файлын жарамсыз кілтпен өңдегенде ескі нәтижелер мен жүктеу батырмасы қалмауы керек.
4. DOCX дайындаңыз. Кестені, атауды немесе транскрипт белгісін өзгертіңіз:
   бұрынғы жүктеу батырмасы жойылып, файлды қайта дайындау қажет болуы керек.
5. Тапсырмасы жоқ түсінікті кеңесті өңдеңіз: бос кестеге қолмен тапсырма қосыңыз.
6. Үнсіз және түсініксіз жазбаларды тексеріңіз: нәтижені автоматты түрде дұрыс деп
   қабылдамаңыз; күтілетін нәтиже — түсініктемесі бар бос тапсырмалар тізімі.
7. Жауапты тұлға мен мерзімді бос қалдырып экспорттаңыз: DOCX ішінде `None`,
   `NaN` орнына «Анықталмады» шығуы керек. Толығымен бос жол экспортталмайды.
8. Ұзын кесте мен қазақ әріптері бар DOCX-ті Word немесе LibreOffice арқылы ашыңыз.

Тест жазбалары мен эталон PDF құжаттары бұл бес файлдың құрамына кірмейді.
Жергілікті регрессиялық тексерулер модель жауаптарын алмастырып орындалады;
олар нақты аудиодағы тану дәлдігін немесе тапсырмаларды табу толықтығын өлшемейді.

## Шектеулер

- Толық акустикалық диаризация жоқ; аттар тізімі оның орнына жүрмейді.
- Шу сүзгісі эвристикалық. Түсініксіз дыбыстан мағыналы жалған транскрипт алынуы мүмкін.
  JSON схемасы мен дәлел үзіндісінің болуы мазмұнның дұрыстығына толық кепілдік бермейді.
- Тапсырмалар қолмен өзгертілгеннен кейін бастапқы дәлел үзіндісі қайта жасалмайды.
- Мерзім бастапқы айтылған түрінде сақталады; салыстырмалы мерзімдер күнтізбелік күнге айналдырылмайды.
- Бір файл 25 МБ-тан, бір транскрипт 60 000 таңбадан аспауы керек. Автоматты бөлу жоқ.
- Модель жауабы көлем шегіне жетсе, толық емес хаттама экспортталмайды: өңдеу қатесі көрсетіледі.
- Бекіту — ағымдағы сессияда DOCX дайындау. Электрондық қолтаңба, аудит журналы,
  дерекқор, еске салу және тапсырмалардың орындалу күйін сақтау жоқ.
- Браузер сессиясы жоғалса, нәтижелер де жоғалуы мүмкін. Жалпыға ашық орналастыруға
  арналған пайдаланушы аутентификациясы бұл нұсқада жоқ.
- DOCX — ұйымның бекітілген ресми бланкісіне сәйкестігі жеке тексерілетін хаттама жобасы.
- Орналастырылған жалпыға қолжетімді нұсқа көрсетілмеген.

## Жабық контурға көшу жоспары

Жоспарланған ағын: ішкі интерфейс → жергілікті аудио өңдеу → Local Whisper
және жергілікті диаризация → уақыт пен сөйлеуші белгісі бар транскрипт
→ vLLM немесе Ollama арқылы жергілікті тілдік модель → схема тексеруі → DOCX.

| Қабат | Жоспарланған өзгеріс |
|---|---|
| Дыбысты тану | `transcribe_audio` ішіндегі API шақыруын жергілікті Whisper орындауымен ауыстыру; тіл таңдауы мен `Transcript` қайтару келісімін сақтау |
| Диаризация | Бөлек жергілікті модульде дауыс бөліктерін ажырату, уақыт аралықтарын транскриптпен біріктіру; белгіні адамның атымен тек расталған сәйкестік арқылы байланыстыру |
| Тілдік модель | `structure_meeting` сұраныстарын ішкі vLLM немесе Ollama серверіне бағыттау; жергілікті модельдің нақты атауын қолдану |
| Клиенттер | Дыбыс пен мәтінге арналған клиенттерді бөлу; қазіргі `get_client` тек сыртқы OpenAI серверіне бағытталған |
| Схема | Таңдалған сервер мен модельдің `json_schema` мүмкіндігін тексеру; Pydantic валидациясын барлық жағдайда сақтау |
| Орналастыру | Модель салмақтарын алдын ала ішкі серверге көшіру, лицензиясын тексеру, сыртқы желіге шығуды бұғаттап толық сценарийді сынау |

vLLM мен Ollama OpenAI-мен үйлесімді интерфейс ұсынады, бірақ нақты параметрлердің
қолдауы сервер мен модельге байланысты. Тілдік модель серверінің мекенжайын өзгерту
Whisper API-ге жіберілетін аудионы автоматты түрде жергілікті етпейді.
Екі өңдеу кезеңін де көшіру қажет. Жергілікті модель қазақша және аралас сөйлеу
эталондарымен тексерілгеннен кейін ғана таңдалады; GPU жады мен жылдамдық өлшенеді.

Қазіргі кодта vLLM, Ollama және Local Whisper қосылмаған. Бұл бөлім оларды іске
қосылған мүмкіндік ретінде көрсетпейді. «GPT-Astra» жергілікті қазақстандық модель
ретінде қолданылмайды және жоба тәуелділігіне кірмейді.

JSON схемасының мүмкіндіктері [OpenAI құжаттамасында](https://developers.openai.com/api/docs/guides/structured-outputs),
аудио шектеулері [транскрипция құжаттамасында](https://developers.openai.com/api/docs/guides/speech-to-text) сипатталған.
Көшу үшін [жергілікті Whisper](https://github.com/openai/whisper),
[vLLM сервері](https://github.com/vllm-project/vllm/blob/main/docs/serving/online_serving/openai_compatible_server.md)
және [Ollama үйлесімділігі](https://docs.ollama.com/api/openai-compatibility) туралы ресми материалдарды пайдаланыңыз.
